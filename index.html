      How it works

      1. Add where each person starts and how they travel.
      2. Meetline looks for places around the fairest middle point, the dashed ring on the map.
      3. Places are ranked by real road times, so no one travels much longer than the rest.

      No account and no server. Locations stay in this browser. A shared link contains each person's map point, so send it only to the group; anyone who opens it can add themselves and send it back.

      Maps, places and routes from OpenStreetMap. Driving, cycling and walking only; no public transport.
