# Meetline design rubric (frozen copy of ~/.vector/skills/hone/design/rubric.md, bullet format for the council)

Judge the screenshots only. Phone (390 px) and desktop (1440 px) count equally. The product: a web map where
2 or more people add their locations and the app shows the fairest place to meet and a road route for each person.

- C1 Specific, not generic (w=0.30): could this screen belong only to this product? Real map, real names and real numbers beat stock shapes and placeholder icons. 4=could be any SaaS template, 7=clearly a meet-up planner with real data, 10=unmistakable, every element is this product's own
- C2 Hierarchy (w=0.20): in 3 seconds a stranger knows what it is and the one next action. One dominant headline or result, one primary button, clear reading order. 4=competing elements, 7=clear result and action, 10=instant read on phone and desktop
- C3 Type and colour with intent (w=0.20): deliberate type pairing (not one default sans), restrained palette with one accent. Purple-to-blue gradients, aurora glows or rainbow accents score 3 or lower. 4=defaults, 7=deliberate pairing and one accent, 10=distinctive and fully consistent
- C4 Signature (w=0.10): one memorable element a person would describe to a friend. 4=none, 7=one clear element, 10=memorable and useful
- C5 Craft (w=0.10): alignment, spacing rhythm, AA contrast, nothing clipped, overlapping or overflowing on phone. 4=visible defects, 7=clean, 10=polished at every width
- C6 Copy (w=0.10): plain claims a user can verify; no hype words, no emoji bullets, no filler. 4=vague or hype, 7=plain and useful, 10=precise, every word earns its place

A version with a slop_check blocker never reaches the judges. Pair mode: pick the version that is better overall
by these weights; call it a tie only if you cannot separate them.
